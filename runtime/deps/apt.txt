# runtime 要額外安裝的 Debian 套件（build 時安裝，執行期不裝任何東西）。
#
# 這個檔案由 `make deps-accept TASK=<進化任務 ID>` 維護，也可以自己手動編輯。
# 它是「沙箱裡驗過 → 人工確認 → 進正式映像」這條路徑的終點，改完要 git commit
# 再 `make build`（或 `make update`）才會生效。流程見 README 的
# 「讓 agent 自由裝套件，確認後再進 runtime」。
#
# 格式：一行一個套件名，# 之後是註解。空行與註解會被忽略。
#
# 為什麼「不」釘版本：Debian 的官方 mirror 在點版本更新後會把舊版本從 pool
# 裡移除，通常只留幾天。釘死版本會讓這個映像在幾週後突然建不起來，而那個
# 失敗跟你當下在改的東西毫無關係。所以這裡只記名稱，把沙箱實際驗到的版本
# 寫成同一行的註解 —— 資訊留著，build 不會因為它而壞掉。
#
# 例（`make deps-accept` 產生的格式）：
#   postgresql-17            # 沙箱驗過 17.10-0+deb13u1（evo-20260811T...）
